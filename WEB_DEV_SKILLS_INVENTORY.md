## Maintenance

### Update skills
```bash
# Global skills
cd C:\Users\your4\.config\opencode\skills
git -C <skill-dir> pull  # for git-cloned skills

# Project skills
cd C:\Users\your4\Projects\animal-marketplace\.agents\skills
git -C <skill-dir> pull  # for git-cloned skills

# modern-web-guidance
npx -y modern-web-guidance@latest update
```

### Uninstall a skill
```bash
# Remove the skill directory
rm -rf C:\Users\your4\.config\opencode\skills\<skill-name>
# or for project-level
rm -rf C:\Users\your4\Projects\animal-marketplace\.agents\skills\<skill-name>
```

### Add a new skill
1. Create a directory in the appropriate skills folder
2. Add a `SKILL.md` file with YAML frontmatter (name, description) and instructions
3. Restart OpenCode to discover the new skill

## Notes

- OpenCode discovers skills automatically from `~/.config/opencode/skills/` and `.agents/skills/` directories
- Skills are loaded on-demand based on the task description
- The agent should prefer the most specialized skill for the current task
- Core skills are foundational; specialized skills are loaded only when relevant
- Context management: avoid loading all skills simultaneously; prefer targeted loading
- The skill inventory should be updated whenever the stack changes
