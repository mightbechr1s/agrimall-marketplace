# AniMAL — Philippine Agricultural Marketplace

Server-side PHP/MySQL implementation that complements the React prototype.

## Stack
- PHP 8.1+ — PDO prepared statements only (see `src/`)
- MySQL 8.0+ — schema in `database/schema.sql`
- Bootstrap 5.3 and Bootstrap Icons, served from `public/assets/vendor/` (offline, no CDN) with a custom brand theme (`public/assets/css/styles.css`)

## Page flow
`public/` is the web root. Pages include `../src/bootstrap.php`, which loads the config,
starts a hardened session, connects via `DB` and registers helpers (`e`, CSRF, flash).

| Page | Purpose |
| --- | --- |
| `index.php` | Landing page: hero, trust bar, how it works, story, FAQ, CTA |
| `browse.php` | Marketplace browse: search, category filter, pagination |
| `listing.php` | Listing detail from verified farms |
| `login.php` / `register.php` / `logout.php` | Authentication (CSRF, `password_hash`) |
| `dashboard.php` | Role-aware home: admin, farmer, buyer |

## Setup (XAMPP)
1. Start **Apache** and **MySQL** in the XAMPP Control Panel.
2. Copy `config/config.example.php` → `config/config.php` (adjust DB creds if needed).
3. Run the reset tool — applies schema, all migrations, and seeds in one command:
   `C:\xampp\php\php.exe tools\db-reset.php --yes`
5. Run the app:

   **New (with custom router for 404/500/sitemap/robots):**
   ```bash
   C:\xampp\php\php.exe -S localhost:8000 -t public public/router.php
   ```

   **Old (without router — 404/500/sitemap/robots not handled):**
   ```bash
   C:\xampp\php\php.exe -S localhost:8000 -t public
   ```

   The `-t public` flag sets the document root. The `public/router.php` argument
   makes the built-in server call the router **only for requests that would otherwise 404**,
   so existing files (assets, PHP pages) are served normally. The router handles:
   - Unknown paths → branded `public/404.php`
   - `/sitemap.xml` → generated by `public/sitemap.php`
   - `/robots.txt` → served as static file (exists in `public/`)
   - Server errors → `public/500.php` (via exception handler in `bootstrap.php`)

6. Open http://localhost:8000

> No internet connection is required. Bootstrap CSS/JS and Bootstrap Icons are
> bundled locally in `public/assets/vendor/`, and no page loads assets from a CDN.

## Security
- Every non-GET request is CSRF-protected (`csrf_abort_if_invalid`, `src/functions.php`)
- All SQL uses PDO prepared statements with emulation disabled (`src/DB.php`)
- Every output value is HTML-escaped via `e()` (`src/functions.php`)
- Passwords hashed with `password_hash()`; sessions hardened in `src/bootstrap.php`
- Security headers: `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`
- **CSP enforced** (not report-only): `default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:; font-src 'self'; connect-src 'self'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'` (all assets are bundled locally; no CDN)
- Exception/error handlers log to `logs/error.log` and render clean 500 page in production

## PWA & Performance
- **PWA manifest** (`public/manifest.json`) — installable, standalone display, shortcuts
- **Service worker** (`public/sw.js`) — cache-first for assets, network-first for pages
- **Preconnect** to `cdn.jsdelivr.net` for faster Bootstrap/Font loading
- **Lazy loading** on all listing images (`loading="lazy"`)
- **Versioned asset queries** (`?v=1`) for cache busting

## Design & UX
- **Apple-inspired fluid interface**: translucent nav & mobile menu (`backdrop-filter: blur(20px) saturate(180%)`), spring-style easings, instant press feedback, interruptible animations
- **Typography**: `font-optical-sizing: auto`, size-specific tracking (`letter-spacing: -0.02em` on headings)
- **Dark mode**: full coverage including trust bar, story section, step cards; respects `prefers-color-scheme`, `prefers-reduced-transparency`, `prefers-reduced-motion`
- **Mockup-aligned landing**: hero CTAs, trust bar (4 pills), How It Works (3 steps), Story, FAQ, CTA — no marketplace grid on landing

## SEO & Crawling
- `public/robots.txt` — allows `/`, disallows `/dashboard`, `/uploads`, `/admin`; references `/sitemap.xml`
- `public/sitemap.php` — serves `/sitemap.xml` with static pages + active listings (priority 0.8, daily changefreq)
- Absolute URLs in sitemap use `config/app.base_url` if set; otherwise derived from request (e.g. `http://localhost:8000`)
- Canonical URLs + hreflang (en/tl) + Open Graph + Twitter Card meta
